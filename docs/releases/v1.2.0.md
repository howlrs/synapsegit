# SynapseGit v1.2.0

`v1.2.0` unifies the released command surface while preserving the frozen v1
Core formats, canonical bytes, OIDs, schemas, Refs, archives, and Human
Decision boundary.

## Changes since v1.1.0

- The release archive has one physical executable: `synapse`.
- Existing Core arguments and behavior remain under `synapse` unchanged.
- The loopback application is `synapse serve` and accepts the former
  `synapse-local` options.
- Presentation bundles use `synapse present export` and `synapse present
  preview` with the former `synapse-present` arguments.
- Each archive provides same-directory relative `synapse-local` and
  `synapse-present` symlinks for compatibility with existing scripts.

`synapse export` remains the checksum-bound Core archive operation. It is
different from `synapse present export`, which derives a read-only presentation
bundle. This release does not claim a speed or archive-size improvement.

The v1.1.0 archive remains a historical three-executable distribution and is
not changed.

## Install and verify

Download the archive and `SHA256SUMS` for this exact release. Verify the
checksum and GitHub build provenance before extracting. If either verification
fails, stop. Do not extract or install an unverified archive. Export important
repositories with the old binary before updating, and retain the old archive
until v1.2.0 verifies the data.

See the tag-fixed [installation guide](https://github.com/howlrs/synapsegit/blob/v1.2.0/docs/install.md),
[changelog](https://github.com/howlrs/synapsegit/blob/v1.2.0/CHANGELOG.md), and
[compatibility policy](https://github.com/howlrs/synapsegit/blob/v1.2.0/docs/compatibility.md).
