# SynapseGit v0.8.1 — Stage 0 preview

`v0.8.1` is a maintenance preview release on top of `v0.8.0`. It adds release
and publication verification coverage without changing the Core v0.1 protocol,
`sg-oid-v1`, directory archive format, localhost API meaning, or the
three-binary distribution. This is a source-available evaluation release, not
a production or hosted service.

## Highlights

- Documentation verification now parses every tracked fenced Bash example with
  `bash -n`, so an invalid shell snippet fails the release gate before it is
  published.
- Workspace dependency diagrams are checked against direct Cargo dependencies,
  preventing diagrams from silently diverging from the workspace manifests.
- Chromium browser coverage now exercises archive export/restore round trips
  and their important rejection paths. Generation-note expanded-form coverage
  now includes its accessibility baseline.
- The independent `0.5.0-draft` localhost OpenAPI revision is registered in an
  immutable revision history. CI rejects a changed registered revision or an
  unregistered revision, while preserving the existing API meaning.
- Publication checks validate the frozen HTML corpus. One named long-string
  reflow defect in the existing corpus remains an approved, exact exception at
  320px and the corresponding 200% CSS zoom approximation. The renderer and
  corpus are unchanged; any other overflow still fails the gate. Screen-reader
  evaluation remains manual.

## Install on Linux x86-64 GNU

The prebuilt archive is produced on Ubuntu 22.04 and requires glibc 2.34 or
newer. Other supported Unix-like hosts can build from the fixed tag with Rust
1.88 or newer.

```bash
curl -LO https://github.com/howlrs/synapsegit/releases/download/v0.8.1/synapsegit-v0.8.1-x86_64-unknown-linux-gnu.tar.gz
curl -LO https://github.com/howlrs/synapsegit/releases/download/v0.8.1/SHA256SUMS
sha256sum --check SHA256SUMS

gh attestation verify synapsegit-v0.8.1-x86_64-unknown-linux-gnu.tar.gz \
  --repo howlrs/synapsegit \
  --signer-workflow howlrs/synapsegit/.github/workflows/release.yml \
  --source-ref refs/tags/v0.8.1 \
  --deny-self-hosted-runners
```

Stop if either verification command fails. Do not extract or install an
unverified archive.

```bash
tar -xzf synapsegit-v0.8.1-x86_64-unknown-linux-gnu.tar.gz

mkdir -p "$HOME/.local/bin"
install -m 0755 synapsegit-v0.8.1-x86_64-unknown-linux-gnu/synapse "$HOME/.local/bin/synapse"
install -m 0755 synapsegit-v0.8.1-x86_64-unknown-linux-gnu/synapse-local "$HOME/.local/bin/synapse-local"
install -m 0755 synapsegit-v0.8.1-x86_64-unknown-linux-gnu/synapse-present "$HOME/.local/bin/synapse-present"
export PATH="$HOME/.local/bin:$PATH"

synapse --version
synapse-local --version
synapse-present --version
```

All three binaries should report `0.8.1`. See the
[installation guide](https://github.com/howlrs/synapsegit/blob/v0.8.1/docs/install.md)
for source installation and update precautions.

## Compatibility and migration

- Repositories created with v0.8.x require no planned format migration. Core
  v0.1 objects, `sg-oid-v1`, directory archive semantics, and localhost API
  meaning are unchanged.
- The release archive contains the same three binaries: `synapse`,
  `synapse-local`, and `synapse-present`. It adds no generic-artifact HTTP,
  CLI, browser, or remote-publication surface.
- The publication reflow exception documents a defect in frozen corpus input;
  it does not make the renderer compliant or change generated content.

Stage 0 APIs and formats do not yet carry a stable compatibility promise.
Export important repositories with the old binary before updating so that a
known-good recovery copy remains available.

## Known limits

- The archive and Creator controls are localhost features; they do not provide
  a public, multi-user, or production service.
- Publication accessibility checks cover static structural and browser
  baselines. A screen-reader evaluation remains manual, and the documented
  frozen-corpus reflow exception remains unresolved.
- Generic-artifact support remains source-library-only. There is no
  generic-artifact HTTP, CLI, browser, or remote-publication surface.
- The prebuilt artifact is Linux x86_64 GNU only. No crates.io, GHCR, Windows,
  macOS, or Linux ARM64 package is published.
