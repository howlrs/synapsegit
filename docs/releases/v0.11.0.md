# SynapseGit v0.11.0 — Stage 0 preview

`v0.11.0` is a Linux x86_64 GNU prerelease for local evaluation. It keeps the
three-binary distribution (`synapse`, `synapse-local`, and `synapse-present`)
and does not change the Core v0.1 protocol, `sg-oid-v1`, directory archive
format, or localhost JSON API payloads. It is not a production, hosted, or
multi-user service.

## Highlights

- `synapse creator-run` now accepts `--generation-note-file PATH`. The file is
  a bounded UTF-8 JSON object containing optional user-declared `tool`,
  `model`, `prompt`, and `intent` fields. The note is private, remains distinct
  from the Human Decision rationale, is preserved by normal archive/restore,
  and is excluded from public bundles. It does not prove a model execution,
  authorship, rights, or permission.
- English readers can complete the tutorial and continue through focused
  Creator workflow, public-text, and privacy/trust guides. Japanese technical
  references remain linked where no English equivalent is provided.
- New Japanese templates support a real-work Creator Pilot: a pre-start
  checklist and a retrospective/continuation decision record. They distinguish
  observations from personal conclusions and do not claim a completed
  real-user evaluation.
- The Creator CLI documentation now makes the decision boundary explicit.
  `creator-run` records exactly one required decision in its process; it does
  not provide deferred CLI decision recovery. Use the localhost Inbox to
  inspect a candidate before deciding, or localhost re-review to make a fresh
  session from an interrupted or deferred proposal.
- Remote GitHub delivery and Git identity/import adapters remain design-only.
  The implemented local public bundle does not upload or publish, GitHub is
  not the object/Ref/reflog authority, and no Git importer, GitHub App,
  remote publisher, or hosted service is included.

## Install on Linux x86-64 GNU

The prebuilt archive is produced on Ubuntu 22.04 and requires glibc 2.34 or
newer. Other supported Unix-like hosts can build from the fixed tag with Rust
1.88 or newer.

```bash
curl -LO https://github.com/howlrs/synapsegit/releases/download/v0.11.0/synapsegit-v0.11.0-x86_64-unknown-linux-gnu.tar.gz
curl -LO https://github.com/howlrs/synapsegit/releases/download/v0.11.0/SHA256SUMS
sha256sum --check SHA256SUMS

gh attestation verify synapsegit-v0.11.0-x86_64-unknown-linux-gnu.tar.gz \
  --repo howlrs/synapsegit \
  --signer-workflow howlrs/synapsegit/.github/workflows/release.yml \
  --source-ref refs/tags/v0.11.0 \
  --deny-self-hosted-runners
```

Stop if either verification command fails. Do not extract or install an
unverified archive.

```bash
tar -xzf synapsegit-v0.11.0-x86_64-unknown-linux-gnu.tar.gz

mkdir -p "$HOME/.local/bin"
install -m 0755 synapsegit-v0.11.0-x86_64-unknown-linux-gnu/synapse "$HOME/.local/bin/synapse"
install -m 0755 synapsegit-v0.11.0-x86_64-unknown-linux-gnu/synapse-local "$HOME/.local/bin/synapse-local"
install -m 0755 synapsegit-v0.11.0-x86_64-unknown-linux-gnu/synapse-present "$HOME/.local/bin/synapse-present"
export PATH="$HOME/.local/bin:$PATH"

synapse --version
synapse-local --version
synapse-present --version
```

All three binaries should report `0.11.0`. See the
[installation guide](https://github.com/howlrs/synapsegit/blob/v0.11.0/docs/install.md)
for source installation and update precautions.

## Compatibility and migration

- Repositories created with v0.10.x require no planned format migration. Core
  v0.1 objects, `sg-oid-v1`, directory archive semantics, and localhost API
  payloads are unchanged.
- The archive contains the same three binaries and adds no generic-artifact
  HTTP, CLI, browser, remote-publication, or hosted-service surface.
- The release archive continues to include the tutorial runner, its synthetic
  sample images, and `TUTORIAL.md` at the archive root, as introduced in
  v0.10.0.

Stage 0 APIs and formats do not yet carry a stable compatibility promise.
Export important repositories with the old binary before updating so that a
known-good recovery copy remains available.

## Known limits

- SynapseGit Local remains loopback-only; it does not provide a public,
  multi-user, or production service. Pending Human review authority stays in
  the running process. Interrupted/Defer reuse starts a new review instead of
  resuming the old one or changing its decision.
- `creator-run --generation-note-file` records caller-supplied private text;
  it does not invoke or verify an AI system.
- The private creator-report JSON and local publication bundle do not publish
  data, add network access, or replace the public projection boundary.
- Generic-artifact support remains source-library-only. There is no
  generic-artifact HTTP, CLI, browser, or remote-publication surface.
- The prebuilt artifact is Linux x86_64 GNU only. No crates.io, GHCR, Windows,
  macOS, or Linux ARM64 package is published.
