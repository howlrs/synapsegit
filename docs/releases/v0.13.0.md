# SynapseGit v0.13.0 — Stage 0 preview

`v0.13.0` is a Linux x86_64 GNU prerelease prepared for local evaluation. It
keeps the three-binary distribution (`synapse`, `synapse-local`, and
`synapse-present`) and makes no intentional change to the Core v0.1 protocol,
`sg-oid-v1`, directory archive format, localhost API revision, CLI contract,
or public bundle format. It is not a production, hosted, or multi-user service.

## Changes since v0.12.0

- The project dashboard still displays at most 200 unverified session summaries:
  pending reviews first, then the most recently updated history. **Open a
  session by name** lets a person open an older session outside that summary
  list when they enter its exact name.
- The name is a case-sensitive strict slug: 1–64 characters, starting with a
  lowercase letter and containing only lowercase letters, digits, and hyphens.
  This is a direct locator, not a full-session search or an expanded listing.
  A nonexistent name follows the existing session-not-found error path.
- The control needs JavaScript to navigate from the validated name. With
  JavaScript disabled, the dashboard remains readable and its summary limit
  remains 200; enable JavaScript to open an older session by name.
- Release verification checks the supplied current CLI version, then exercises
  the pinned v0.11.1 source commit and, when distinct, the latest eligible
  local annotated ancestor release below the current CLI version. Each
  baseline creates a synthetic private Defer session and verifies old archive
  to current restore, `fsck`, and native JSON report preservation, followed by
  current re-export, re-restore, `fsck`, and exact native JSON equality. Old
  fields must remain present; additive current fields are allowed.

This archive gate is a focused regression baseline. It does not promise general
compatibility for arbitrary repositories, all historical releases, or future
formats. Local runs default to cached offline dependencies; controlled CI or
release runs can permit the archived old Cargo build to obtain dependencies.

The existing completed-session **Save private record (JSON)** capability is
unchanged. It remains a private native session response, separate from public
bundles, repository backups, and the CLI-owned `creator-report --format json`
document.

## Install on Linux x86-64 GNU

After the tag workflow publishes the prerelease, the prebuilt archive is
produced on Ubuntu 22.04 and requires glibc 2.34 or newer. Other supported
Unix-like hosts can build from the fixed tag with Rust 1.88 or newer.

```bash
curl -LO https://github.com/howlrs/synapsegit/releases/download/v0.13.0/synapsegit-v0.13.0-x86_64-unknown-linux-gnu.tar.gz
curl -LO https://github.com/howlrs/synapsegit/releases/download/v0.13.0/SHA256SUMS
sha256sum --check SHA256SUMS

gh attestation verify synapsegit-v0.13.0-x86_64-unknown-linux-gnu.tar.gz \
  --repo howlrs/synapsegit \
  --signer-workflow howlrs/synapsegit/.github/workflows/release.yml \
  --source-ref refs/tags/v0.13.0 \
  --deny-self-hosted-runners
```

Stop if either verification command fails. Do not extract or install an
unverified archive.

```bash
tar -xzf synapsegit-v0.13.0-x86_64-unknown-linux-gnu.tar.gz

mkdir -p "$HOME/.local/bin"
install -m 0755 synapsegit-v0.13.0-x86_64-unknown-linux-gnu/synapse "$HOME/.local/bin/synapse"
install -m 0755 synapsegit-v0.13.0-x86_64-unknown-linux-gnu/synapse-local "$HOME/.local/bin/synapse-local"
install -m 0755 synapsegit-v0.13.0-x86_64-unknown-linux-gnu/synapse-present "$HOME/.local/bin/synapse-present"
export PATH="$HOME/.local/bin:$PATH"

synapse --version
synapse-local --version
synapse-present --version
```

All three binaries should report `0.13.0`. See the
[installation guide](https://github.com/howlrs/synapsegit/blob/v0.13.0/docs/install.md)
for source installation and update precautions.

## Compatibility and limits

- No format or API migration is planned from v0.12.0. Core v0.1 objects,
  `sg-oid-v1`, directory archives, and localhost API revision are unchanged.
- The archive still includes the tutorial runner, its synthetic sample images,
  and `TUTORIAL.md` at the archive root.
- SynapseGit Local remains loopback-only; it does not provide a public,
  multi-user, or production service. Remote GitHub delivery and Git
  identity/import adapters remain design-only.
- The prebuilt artifact is Linux x86_64 GNU only. No crates.io, GHCR, Windows,
  macOS, or Linux ARM64 package is published.

Stage 0 APIs and formats do not yet carry a stable compatibility promise.
Export important repositories with the old binary before updating so that a
known-good recovery copy remains available.
