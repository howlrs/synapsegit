# SynapseGit v1.1.0

`v1.1.0` improves local Creator input safety, private automation output, and
release-platform behavior. It preserves frozen v1 Core formats, canonical
bytes, OIDs, schemas, Refs, archives, and the Human Decision boundary.

## Changes since v1.0.1

- Creator inputs are retained through a non-blocking regular-file path before
  recording. FIFO, directory, and socket inputs fail without repository
  mutation; errors identify the creator input and include an actionable hint.
- `creator-run` and `inbox decide` support `--format json`, returning one
  private-local `synapsegit-cli-creator-decision-v1` document with a receipt,
  verified report, and metadata warnings. Do not share this output.
- Bounded PNG/JPEG metadata inspection recognizes trailer structure without
  treating unknown trailing data as image or GPS evidence. The scanner does
  not provide real-device GPS evidence.
- Publication replacement handles Linux and macOS safely. The Japanese
  renderer-v2 projection and re-export are available without changing the
  frozen v1 public projection contract.

No fourth binary or new distribution channel is added. Linux x86_64 GNU and
macOS arm64 archives remain the supported prebuilt assets; Windows remains
unsupported.

## Install and verify

Download the archive and `SHA256SUMS` for this exact release. Verify checksum
and GitHub build provenance before extracting. If either verification fails, stop.
Do not extract or install an unverified archive. Export important repositories with the old binary before
updating, then retain the old archive until v1.1.0 verifies the data.

See the tag-fixed [installation guide](https://github.com/howlrs/synapsegit/blob/v1.1.0/docs/install.md),
[changelog](https://github.com/howlrs/synapsegit/blob/v1.1.0/CHANGELOG.md), and
[compatibility policy](https://github.com/howlrs/synapsegit/blob/v1.1.0/docs/compatibility.md).
