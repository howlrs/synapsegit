# SynapseGit v0.13.1 — Stage 0 preview

`v0.13.1` is a Linux x86_64 GNU prerelease prepared for local evaluation. It
keeps the three-binary distribution and makes no intentional end-user CLI,
browser, API, schema, Core protocol, OID, archive-format, or public-bundle
change.

## Changes since v0.13.0

- CI browser regression jobs use optimized release binaries, the same profile
  already used for packaging, instead of debug binaries. Assertions, timeout
  values, retries, and the default local debug development workflow are
  unchanged. This follows three navigation timeouts in the v0.13.0 main CI.
- The Inbox decision browser test now waits explicitly for the asynchronous
  decision reload before checking the recorded heading, matching the existing
  decision tests.
- The v0.13.0 Observation implementation bundle was audited to confirm that
  its previous archive report remains readable after this version bump. The
  archive regression gate continues to validate the pinned v0.11.1 baseline
  and the latest eligible annotated ancestor baseline, currently v0.13.0.

The v0.13.0 dashboard locator is unchanged.

## Install on Linux x86-64 GNU

After the tag workflow publishes the prerelease, download and verify the fixed
release archive as described in the [installation guide](https://github.com/howlrs/synapsegit/blob/v0.13.1/docs/install.md).
The prebuilt archive is Linux x86_64 GNU for glibc 2.34 or newer; tagged source
builds require Rust 1.88 or newer.

## Compatibility and limits

- No format or API migration is planned from v0.13.0. Core v0.1 objects,
  `sg-oid-v1`, directory archives, and localhost API revision are unchanged.
- Stage 0 APIs and formats do not carry a stable compatibility promise.
- SynapseGit Local remains loopback-only. No crates.io, GHCR, Windows, macOS,
  or Linux ARM64 package is published.
