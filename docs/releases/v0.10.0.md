# SynapseGit v0.10.0 — Stage 0 preview

`v0.10.0` is a Linux x86_64 GNU prerelease for local evaluation. It keeps the
existing three-binary distribution (`synapse`, `synapse-local`, and
`synapse-present`) and does not change the Core v0.1 protocol, `sg-oid-v1`,
directory archive format, or localhost JSON API payloads. It is not a production,
hosted, or multi-user service.

## Highlights

- The release archive now includes the mural tutorial runner, its three
  synthetic sample images, and a bilingual `TUTORIAL.md` at the archive root.
  The tutorial can run from an extracted archive with the three binaries on
  `PATH`; it needs no network access at run time.
- `synapse creator-report REPOSITORY SESSION --format json` now emits one versioned,
  private-local JSON report for local tooling. The default line-oriented text
  report remains available, and the JSON report is separate from public
  publication bundles.
- SynapseGit Local provides Japanese and English application labels,
  accessible names, client messages, and image alternatives. A header choice
  is retained in the browser and takes priority over `Accept-Language`; user
  text, stored text, API identifiers, and error codes are not translated.
- The bilingual Creator Pilot evaluation kit in the tagged source documents a first recorded
  decision and separate facilitator observations. It is a documentation kit,
  not a scorer or a claim of a completed real-user evaluation.
- The presentation deck in the tagged source remains deliberately fixed to the reviewed
  v0.9.0 scenario and release tag. It is an evaluation aid, not a promise of
  capture tooling, pixel comparison, production HTTP/JWT authentication, or a
  general-purpose creator application.

## Install on Linux x86-64 GNU

The prebuilt archive is produced on Ubuntu 22.04 and requires glibc 2.34 or
newer. Other supported Unix-like hosts can build from the fixed tag with Rust
1.88 or newer.

```bash
curl -LO https://github.com/howlrs/synapsegit/releases/download/v0.10.0/synapsegit-v0.10.0-x86_64-unknown-linux-gnu.tar.gz
curl -LO https://github.com/howlrs/synapsegit/releases/download/v0.10.0/SHA256SUMS
sha256sum --check SHA256SUMS

gh attestation verify synapsegit-v0.10.0-x86_64-unknown-linux-gnu.tar.gz \
  --repo howlrs/synapsegit \
  --signer-workflow howlrs/synapsegit/.github/workflows/release.yml \
  --source-ref refs/tags/v0.10.0 \
  --deny-self-hosted-runners
```

Stop if either verification command fails. Do not extract or install an
unverified archive.

```bash
tar -xzf synapsegit-v0.10.0-x86_64-unknown-linux-gnu.tar.gz

mkdir -p "$HOME/.local/bin"
install -m 0755 synapsegit-v0.10.0-x86_64-unknown-linux-gnu/synapse "$HOME/.local/bin/synapse"
install -m 0755 synapsegit-v0.10.0-x86_64-unknown-linux-gnu/synapse-local "$HOME/.local/bin/synapse-local"
install -m 0755 synapsegit-v0.10.0-x86_64-unknown-linux-gnu/synapse-present "$HOME/.local/bin/synapse-present"
export PATH="$HOME/.local/bin:$PATH"

synapse --version
synapse-local --version
synapse-present --version
```

All three binaries should report `0.10.0`. See the
[installation guide](https://github.com/howlrs/synapsegit/blob/v0.10.0/docs/install.md)
for source installation and update precautions.

## Compatibility and migration

- Repositories created with v0.9.x require no planned format migration. Core
  v0.1 objects, `sg-oid-v1`, directory archive semantics, and localhost API
  payloads are unchanged.
- The archive contains the same three binaries and adds no generic-artifact
  HTTP, CLI, browser, or remote-publication surface.
- Tutorial runner and sample-image paths are new to the v0.10.0 archive.
  Existing v0.9.0 archives remain unchanged and do not contain them.
- The Creator Pilot kit and presentation deck retain their explicit v0.9.0
  target. Use v0.9.0 when following those version-specific materials; they do
  not describe the new v0.10.0 language selector or JSON report. These materials
  are available in the tagged source, separately from the binary archive.

Stage 0 APIs and formats do not yet carry a stable compatibility promise.
Export important repositories with the old binary before updating so that a
known-good recovery copy remains available.

## Known limits

- SynapseGit Local remains loopback-only; it does not provide a public,
  multi-user, or production service. Pending Human review authority stays in
  the running process. Interrupted/Defer reuse starts a new review instead of
  resuming the old one or changing its decision.
- The private creator-report JSON is local tooling output. It does not publish
  data, add network access, or replace the public projection boundary.
- Generic-artifact support remains source-library-only. There is no
  generic-artifact HTTP, CLI, browser, or remote-publication surface.
- The prebuilt artifact is Linux x86_64 GNU only. No crates.io, GHCR, Windows,
  macOS, or Linux ARM64 package is published.
