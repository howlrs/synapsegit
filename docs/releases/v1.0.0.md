# SynapseGit v1.0.0

`v1.0.0` is the first stable SynapseGit v1 product release. It keeps the v1
format promise for `sg-oid-v1`, Core record schemas, the directory archive
profile, import inbox manifest v1, and CLI JSON documents (additive fields
only). Current binaries read repositories, archives, and Creator sessions from
every published release.

The real-user 3–5-person Creator pilot has not yet been conducted. Its work is
tracked in [#192](https://github.com/howlrs/synapsegit/issues/192), which
remains open. The synthetic rehearsal, automated checks, and documentation
captures do not substitute for real-user evidence.

## Release contents and limits

- Linux x86_64 GNU and macOS arm64 (Apple Silicon) archives are built, tested,
  smoke-tested, and attested by the tag workflow. One `SHA256SUMS` lists both
  archives.
- The macOS binaries are not signed or notarized. Linux requires glibc 2.34 or
  newer. Linux ARM64 and Windows have no prebuilt archive.
- `synapse-local` remains loopback-only at `127.0.0.1`. Do not expose it through
  a reverse proxy or use it as a multi-user or hosted service.
- SynapseGit does not run AI models, prove who made a file or whether a depicted
  subject changed, provide image-difference analysis, or make a recorded Human
  Decision editable.
- Documentation images are a 2026-10-02 material revision. The localhost UI
  captures use a SHA-256-verified `v1.0.0-rc.1` archive; they illustrate the
  product and are distinct from the bytes in this v1.0.0 release bundle.

Read the [changelog](https://github.com/howlrs/synapsegit/blob/v1.0.0/CHANGELOG.md)
and [compatibility policy](https://github.com/howlrs/synapsegit/blob/v1.0.0/docs/compatibility.md)
before updating an existing repository.

## Install and verify

Download only the archive for your platform and the matching `SHA256SUMS` from
this release. Verify both the SHA-256 checksum and GitHub build provenance
before extracting it. If either verification fails, stop. Do not extract or install an unverified archive.

### Linux x86-64 GNU

```bash
curl -LO https://github.com/howlrs/synapsegit/releases/download/v1.0.0/synapsegit-v1.0.0-x86_64-unknown-linux-gnu.tar.gz
curl -LO https://github.com/howlrs/synapsegit/releases/download/v1.0.0/SHA256SUMS
sha256sum --check --ignore-missing SHA256SUMS
gh attestation verify synapsegit-v1.0.0-x86_64-unknown-linux-gnu.tar.gz \
  --repo howlrs/synapsegit \
  --signer-workflow howlrs/synapsegit/.github/workflows/release.yml \
  --source-ref refs/tags/v1.0.0 \
  --deny-self-hosted-runners
tar -xzf synapsegit-v1.0.0-x86_64-unknown-linux-gnu.tar.gz
mkdir -p "$HOME/.local/bin"
for binary in synapse synapse-local synapse-present; do
  install -m 0755 "synapsegit-v1.0.0-x86_64-unknown-linux-gnu/$binary" "$HOME/.local/bin/$binary"
done
export PATH="$HOME/.local/bin:$PATH"
synapse --version
```

### macOS arm64 (Apple Silicon)

```bash
curl -LO https://github.com/howlrs/synapsegit/releases/download/v1.0.0/synapsegit-v1.0.0-aarch64-apple-darwin.tar.gz
curl -LO https://github.com/howlrs/synapsegit/releases/download/v1.0.0/SHA256SUMS
grep 'synapsegit-v1.0.0-aarch64-apple-darwin.tar.gz' SHA256SUMS | shasum -a 256 --check
gh attestation verify synapsegit-v1.0.0-aarch64-apple-darwin.tar.gz \
  --repo howlrs/synapsegit \
  --signer-workflow howlrs/synapsegit/.github/workflows/release.yml \
  --source-ref refs/tags/v1.0.0 \
  --deny-self-hosted-runners
tar -xzf synapsegit-v1.0.0-aarch64-apple-darwin.tar.gz
mkdir -p "$HOME/.local/bin"
for binary in synapse synapse-local synapse-present; do
  install -m 0755 "synapsegit-v1.0.0-aarch64-apple-darwin/$binary" "$HOME/.local/bin/$binary"
done
export PATH="$HOME/.local/bin:$PATH"
synapse --version
```

On macOS, browser-downloaded files may have a quarantine attribute. Only after
both checks pass, remove it from installed binaries if macOS blocks them:

```bash
xattr -d com.apple.quarantine "$HOME/.local/bin/synapse" "$HOME/.local/bin/synapse-local" "$HOME/.local/bin/synapse-present"
```

The full, tag-fixed installation guide is
https://github.com/howlrs/synapsegit/blob/v1.0.0/docs/install.md.

## Compatibility and migration

The v1 formats are frozen for v1.x. This release reads data from every
published release, including `v1.0.0-rc.1`; older binaries may refuse Creator
sessions recorded by a newer binary. Export important repositories with the old binary before updating.
Keep the old binary and archive until the new version has verified the data.

Use only a fixed tag for source installation or review.
