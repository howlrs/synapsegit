# SynapseGit v0.11.1 — Stage 0 preview

`v0.11.1` is a Linux x86_64 GNU prerelease for local evaluation. This is a
maintenance update to v0.11.0. It keeps the three-binary distribution
(`synapse`, `synapse-local`, and `synapse-present`) and makes no intentional
change to the Core v0.1 protocol, `sg-oid-v1`, directory archive format, or
localhost JSON API payloads. It is not a production, hosted, or multi-user
service.

## Changes since v0.11.0

- The JSON Schema validation dependency is updated from 0.49.2 to 0.57.0.
  The lockfile and third-party notices include its updated dependency set.
- The release attestation and CI cache actions are updated to
  `actions/attest` v4.2.2 and `Swatinem/rust-cache` v2.9.2, respectively.
- Archive export and restore HTTP tests use a bounded wait for asynchronous
  completion, so a busy CI runner does not produce a false failure.

This release adds no new CLI, browser, publication, or hosted-service feature.

## Install on Linux x86-64 GNU

The prebuilt archive is produced on Ubuntu 22.04 and requires glibc 2.34 or
newer. Other supported Unix-like hosts can build from the fixed tag with Rust
1.88 or newer.

```bash
curl -LO https://github.com/howlrs/synapsegit/releases/download/v0.11.1/synapsegit-v0.11.1-x86_64-unknown-linux-gnu.tar.gz
curl -LO https://github.com/howlrs/synapsegit/releases/download/v0.11.1/SHA256SUMS
sha256sum --check SHA256SUMS

gh attestation verify synapsegit-v0.11.1-x86_64-unknown-linux-gnu.tar.gz \
  --repo howlrs/synapsegit \
  --signer-workflow howlrs/synapsegit/.github/workflows/release.yml \
  --source-ref refs/tags/v0.11.1 \
  --deny-self-hosted-runners
```

Stop if either verification command fails. Do not extract or install an
unverified archive.

```bash
tar -xzf synapsegit-v0.11.1-x86_64-unknown-linux-gnu.tar.gz

mkdir -p "$HOME/.local/bin"
install -m 0755 synapsegit-v0.11.1-x86_64-unknown-linux-gnu/synapse "$HOME/.local/bin/synapse"
install -m 0755 synapsegit-v0.11.1-x86_64-unknown-linux-gnu/synapse-local "$HOME/.local/bin/synapse-local"
install -m 0755 synapsegit-v0.11.1-x86_64-unknown-linux-gnu/synapse-present "$HOME/.local/bin/synapse-present"
export PATH="$HOME/.local/bin:$PATH"

synapse --version
synapse-local --version
synapse-present --version
```

All three binaries should report `0.11.1`. See the
[installation guide](https://github.com/howlrs/synapsegit/blob/v0.11.1/docs/install.md)
for source installation and update precautions.

## Compatibility and limits

- No format or API migration is planned from v0.11.0. Core v0.1 objects,
  `sg-oid-v1`, directory archives, and localhost API payloads are unchanged by
  this release's source changes.
- The archive still includes the tutorial runner, its synthetic sample images,
  and `TUTORIAL.md` at the archive root.
- SynapseGit Local remains loopback-only; it does not provide a public,
  multi-user, or production service. Remote GitHub delivery and Git
  identity/import adapters remain design-only.
- The prebuilt artifact is Linux x86_64 GNU only. No crates.io, GHCR, Windows,
  macOS, or Linux ARM64 package is published.

Stage 0 APIs and formats do not yet carry a stable compatibility promise.
Export important repositories with the old binary before updating so that a
known-good recovery copy remains available.
