# SynapseGit v1.0.0-rc.1 — release candidate

`v1.0.0-rc.1` is a prerelease for the [v1.0 real-user pilot](https://github.com/howlrs/synapsegit/issues/192):
3–5 people in the intended audience use the Creator pilot evaluation kit v2.
It is not the final v1.0.0 release. Report problems through the pilot process
or [SUPPORT.md](https://github.com/howlrs/synapsegit/blob/v1.0.0-rc.1/SUPPORT.md);
do not treat this candidate as a production, hosted, or multi-user deployment.

## Highlights since v0.13.1

- The v1 formats are frozen for v1.x: `sg-oid-v1`, Core record schemas, the
  directory archive profile, import inbox manifest v1, and CLI JSON documents
  (additive fields only). Current binaries read repositories, archives, and
  Creator sessions from every published release.
- The first macOS arm64 (Apple Silicon) archive is published beside Linux
  x86_64. Each platform is built, tested, packaged, smoke-tested, and
  attested; one `SHA256SUMS` lists both archives. The macOS binaries are not
  signed or notarized.
- An AI agent can use `synapse inbox put` to prepare a candidate without
  recording a decision. The person reviews it in `synapse-local` and records
  Adopt, Reject, or Defer. The UI uses plainer words, separates Sessions,
  Import, Maintenance, and History, and has completed Japanese labels.
- `synapse creator-list` provides a bounded overview of Creator sessions, and
  commands provide subcommand help and next-step hints for common errors.
- The archive contains the AI-agent guides. The Creator pilot evaluation kit
  v2 and its synthetic rehearsal do not replace the real-user pilot required
  before a final v1.0.0 release.

Read the [changelog](https://github.com/howlrs/synapsegit/blob/v1.0.0-rc.1/CHANGELOG.md)
for the complete list of changes since v0.13.1 and the
[v1.0 release plan](https://github.com/howlrs/synapsegit/blob/v1.0.0-rc.1/docs/v1_release_plan.md)
for the v1.0 release conditions.

## Install and verify

Download only the archive for your platform and the matching `SHA256SUMS` from
this release. Verify both the SHA-256 checksum and GitHub build provenance
before extracting it. If either verification fails, stop. Do not extract or install an unverified archive.

### Linux x86-64 GNU

Linux requires glibc 2.34 or newer.

```bash
curl -LO https://github.com/howlrs/synapsegit/releases/download/v1.0.0-rc.1/synapsegit-v1.0.0-rc.1-x86_64-unknown-linux-gnu.tar.gz
curl -LO https://github.com/howlrs/synapsegit/releases/download/v1.0.0-rc.1/SHA256SUMS
sha256sum --check --ignore-missing SHA256SUMS
gh attestation verify synapsegit-v1.0.0-rc.1-x86_64-unknown-linux-gnu.tar.gz \
  --repo howlrs/synapsegit \
  --signer-workflow howlrs/synapsegit/.github/workflows/release.yml \
  --source-ref refs/tags/v1.0.0-rc.1 \
  --deny-self-hosted-runners
tar -xzf synapsegit-v1.0.0-rc.1-x86_64-unknown-linux-gnu.tar.gz
mkdir -p "$HOME/.local/bin"
for binary in synapse synapse-local synapse-present; do
  install -m 0755 "synapsegit-v1.0.0-rc.1-x86_64-unknown-linux-gnu/$binary" "$HOME/.local/bin/$binary"
done
export PATH="$HOME/.local/bin:$PATH"
synapse --version
```

### macOS arm64 (Apple Silicon)

```bash
curl -LO https://github.com/howlrs/synapsegit/releases/download/v1.0.0-rc.1/synapsegit-v1.0.0-rc.1-aarch64-apple-darwin.tar.gz
curl -LO https://github.com/howlrs/synapsegit/releases/download/v1.0.0-rc.1/SHA256SUMS
grep 'synapsegit-v1.0.0-rc.1-aarch64-apple-darwin.tar.gz' SHA256SUMS | shasum -a 256 --check
gh attestation verify synapsegit-v1.0.0-rc.1-aarch64-apple-darwin.tar.gz \
  --repo howlrs/synapsegit \
  --signer-workflow howlrs/synapsegit/.github/workflows/release.yml \
  --source-ref refs/tags/v1.0.0-rc.1 \
  --deny-self-hosted-runners
tar -xzf synapsegit-v1.0.0-rc.1-aarch64-apple-darwin.tar.gz
mkdir -p "$HOME/.local/bin"
for binary in synapse synapse-local synapse-present; do
  install -m 0755 "synapsegit-v1.0.0-rc.1-aarch64-apple-darwin/$binary" "$HOME/.local/bin/$binary"
done
export PATH="$HOME/.local/bin:$PATH"
synapse --version
```

On macOS, browser-downloaded files may have a quarantine attribute. Only after
both checks pass, remove it from installed binaries if macOS blocks them:

```bash
xattr -d com.apple.quarantine "$HOME/.local/bin/synapse" "$HOME/.local/bin/synapse-local" "$HOME/.local/bin/synapse-present"
```

The full, tag-fixed installation guide is
https://github.com/howlrs/synapsegit/blob/v1.0.0-rc.1/docs/install.md.

## Compatibility and migration

v1.0.0-rc.1 is the candidate for the v1 format promise, but it does not make
the final v1.0.0 release decision. It reads data from every published release;
v0.13.1 and older binaries may refuse Creator sessions recorded by this newer
candidate. Export important repositories with the old binary before updating.
Keep the old binary and archive until the candidate has verified the data.

Use only a fixed tag for source installation or review. The general installation
guide retains v0.13.1 as the latest non-RC preview example; these commands
are specifically for the pilot candidate. Linux ARM64 and Windows have no
prebuilt archive.

`synapse-local` remains loopback-only at `127.0.0.1`. Do not expose it through
a reverse proxy or use it as a multi-user or hosted service.

## Known limits

This candidate does not run AI models, prove who made a file or whether a
depicted subject changed, provide image-difference analysis, or make a recorded
decision editable. macOS support is Apple Silicon only; the binaries are not
signed or notarized. The pilot may uncover issues that delay or change the
final v1.0.0 release.
