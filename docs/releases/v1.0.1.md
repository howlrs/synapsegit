# SynapseGit v1.0.1

`v1.0.1` is a patch release for local single-user use. It fixes three input and
CLI-output defects found in v1.0.0 and preserves the frozen v1 formats,
canonical bytes, OIDs, Core schemas, Refs, archives, and Human Decision boundary.

## Changes since v1.0.0

- Long Inbox slugs now get a suggested session name within the 64-byte limit.
  Short slugs keep `inbox-<slug>`; long slugs use a shortened prefix and eight
  hexadecimal digits of SHA-256. Preview and imported-candidate marking use
  the same rule (localhost API `0.6.9-draft`). The local public-text form may
  request only the selected complete session's verified Subject and Creator as
  opt-in suggestions; they remain author-supplied public text only after an
  explicit confirmation.
- Generation notes and Inbox manifests are read only from JSON objects, as
  documented. Positional arrays are rejected before creating a repository or
  Inbox candidate. Previously written valid objects remain readable.
- `synapse` and `synapse-present` no longer panic when a stdout pipe closes
  early. They retain the command's own exit status; other stdout failures
  return `storage_error` with exit code 1.
- The v1.0.0 byte-identity implementation bundle is explicitly recognized after
  the version bump. Release fixtures continue to verify repositories and
  archives written by every earlier published release.

No real-user Creator pilot has been conducted. The multi-AI operational trials
used for the v1.0.0 release gate remain synthetic evaluation evidence, not
people, consent, user experience, or a Human Decision.

## Release contents and limits

- Linux x86_64 GNU and macOS arm64 (Apple Silicon) archives are built, tested,
  smoke-tested, and attested by the tag workflow. One `SHA256SUMS` lists both
  archives.
- The macOS binaries are not signed or notarized. Linux requires glibc 2.34 or
  newer. Linux ARM64 and Windows have no prebuilt archive.
- `synapse-local` remains loopback-only at `127.0.0.1`. Do not expose it through
  a reverse proxy or use it as a multi-user or hosted service.
- SynapseGit does not run AI models, prove who made a file or whether a depicted
  subject changed, provide image-difference analysis, or make a recorded Human
  Decision editable.
- Documentation images are a 2026-10-02 material revision. The localhost UI
  captures use a SHA-256-verified `v1.0.0-rc.1` archive; they illustrate the
  product and are distinct from the bytes in this v1.0.1 release bundle.

Read the [changelog](https://github.com/howlrs/synapsegit/blob/v1.0.1/CHANGELOG.md)
and [compatibility policy](https://github.com/howlrs/synapsegit/blob/v1.0.1/docs/compatibility.md)
before updating an existing repository.

## Install and verify

Download only the archive for your platform and the matching `SHA256SUMS` from
this release. Verify both the SHA-256 checksum and GitHub build provenance
before extracting it. If either verification fails, stop. Do not extract or install an unverified archive.

### Linux x86-64 GNU

```bash
curl -fLO https://github.com/howlrs/synapsegit/releases/download/v1.0.1/synapsegit-v1.0.1-x86_64-unknown-linux-gnu.tar.gz
curl -fLO https://github.com/howlrs/synapsegit/releases/download/v1.0.1/SHA256SUMS
sha256sum --check --ignore-missing SHA256SUMS &&
gh attestation verify synapsegit-v1.0.1-x86_64-unknown-linux-gnu.tar.gz \
  --repo howlrs/synapsegit \
  --signer-workflow howlrs/synapsegit/.github/workflows/release.yml \
  --source-ref refs/tags/v1.0.1 \
  --deny-self-hosted-runners
```

Continue only if both verification checks succeeded. Then extract and install:

```bash
tar -xzf synapsegit-v1.0.1-x86_64-unknown-linux-gnu.tar.gz
mkdir -p "$HOME/.local/bin"
for binary in synapse synapse-local synapse-present; do
  install -m 0755 "synapsegit-v1.0.1-x86_64-unknown-linux-gnu/$binary" "$HOME/.local/bin/$binary"
done
export PATH="$HOME/.local/bin:$PATH"
synapse --version
```

### macOS arm64 (Apple Silicon)

```bash
curl -fLO https://github.com/howlrs/synapsegit/releases/download/v1.0.1/synapsegit-v1.0.1-aarch64-apple-darwin.tar.gz
curl -fLO https://github.com/howlrs/synapsegit/releases/download/v1.0.1/SHA256SUMS
grep 'synapsegit-v1.0.1-aarch64-apple-darwin.tar.gz' SHA256SUMS | shasum -a 256 --check &&
gh attestation verify synapsegit-v1.0.1-aarch64-apple-darwin.tar.gz \
  --repo howlrs/synapsegit \
  --signer-workflow howlrs/synapsegit/.github/workflows/release.yml \
  --source-ref refs/tags/v1.0.1 \
  --deny-self-hosted-runners
```

Continue only if both verification checks succeeded. Then extract and install:

```bash
tar -xzf synapsegit-v1.0.1-aarch64-apple-darwin.tar.gz
mkdir -p "$HOME/.local/bin"
for binary in synapse synapse-local synapse-present; do
  install -m 0755 "synapsegit-v1.0.1-aarch64-apple-darwin/$binary" "$HOME/.local/bin/$binary"
done
export PATH="$HOME/.local/bin:$PATH"
synapse --version
```

On macOS, browser-downloaded files may have a quarantine attribute. Only after
both checks pass, remove it from installed binaries if macOS blocks them:

```bash
xattr -d com.apple.quarantine "$HOME/.local/bin/synapse" "$HOME/.local/bin/synapse-local" "$HOME/.local/bin/synapse-present"
```

The full, tag-fixed installation guide is
https://github.com/howlrs/synapsegit/blob/v1.0.1/docs/install.md.

## Compatibility and migration

The v1 formats are frozen for v1.x. This release reads data from every
published release, including `v1.0.0` and `v1.0.0-rc.1`; older binaries may refuse Creator
sessions recorded by a newer binary. Export important repositories with the old binary before updating.
Keep the old binary and archive until the new version has verified the data.

Use only a fixed tag for source installation or review.
