# SynapseGit v0.12.0 — Stage 0 preview

`v0.12.0` is a Linux x86_64 GNU prerelease for local evaluation. It keeps the
three-binary distribution (`synapse`, `synapse-local`, and `synapse-present`)
and makes no intentional change to the Core v0.1 protocol, `sg-oid-v1`,
directory archive format, localhost API revision, CLI contract, or public
bundle format. It is not a production, hosted, or multi-user service.

## Changes since v0.11.1

- A completed Creator session page offers **Save private record (JSON)**. The
  browser fetches the existing authenticated
  `GET /api/v1/projects/{project}/creator-sessions/{session}` endpoint again
  when the person clicks download. It downloads the fresh complete response
  unchanged, with the shape `{"state":"complete","report":{...}}`.
- The control is absent for pending and incomplete sessions. If the fresh
  verification or read fails, no report download is produced.
- When the stored report contains them, the private download can include the
  Human Decision rationale, user-declared `generation_note`, decision
  annotations or pins, internal identifiers, and source lineage. Treat it as
  private repository data and share it only with people permitted to see that
  material.

This browser download is neither a public presentation bundle nor a repository
backup. Its native response is a local browser convenience over the existing
authenticated endpoint. It is not interchangeable with the separately owned
`synapse creator-report --format json` document.

## Install on Linux x86-64 GNU

The prebuilt archive is produced on Ubuntu 22.04 and requires glibc 2.34 or
newer. Other supported Unix-like hosts can build from the fixed tag with Rust
1.88 or newer.

```bash
curl -LO https://github.com/howlrs/synapsegit/releases/download/v0.12.0/synapsegit-v0.12.0-x86_64-unknown-linux-gnu.tar.gz
curl -LO https://github.com/howlrs/synapsegit/releases/download/v0.12.0/SHA256SUMS
sha256sum --check SHA256SUMS

gh attestation verify synapsegit-v0.12.0-x86_64-unknown-linux-gnu.tar.gz \
  --repo howlrs/synapsegit \
  --signer-workflow howlrs/synapsegit/.github/workflows/release.yml \
  --source-ref refs/tags/v0.12.0 \
  --deny-self-hosted-runners
```

Stop if either verification command fails. Do not extract or install an
unverified archive.

```bash
tar -xzf synapsegit-v0.12.0-x86_64-unknown-linux-gnu.tar.gz

mkdir -p "$HOME/.local/bin"
install -m 0755 synapsegit-v0.12.0-x86_64-unknown-linux-gnu/synapse "$HOME/.local/bin/synapse"
install -m 0755 synapsegit-v0.12.0-x86_64-unknown-linux-gnu/synapse-local "$HOME/.local/bin/synapse-local"
install -m 0755 synapsegit-v0.12.0-x86_64-unknown-linux-gnu/synapse-present "$HOME/.local/bin/synapse-present"
export PATH="$HOME/.local/bin:$PATH"

synapse --version
synapse-local --version
synapse-present --version
```

All three binaries should report `0.12.0`. See the
[installation guide](https://github.com/howlrs/synapsegit/blob/v0.12.0/docs/install.md)
for source installation and update precautions.

## Compatibility and limits

- No format or API migration is planned from v0.11.1. Core v0.1 objects,
  `sg-oid-v1`, directory archives, and localhost API revision are unchanged.
- The archive still includes the tutorial runner, its synthetic sample images,
  and `TUTORIAL.md` at the archive root.
- SynapseGit Local remains loopback-only; it does not provide a public,
  multi-user, or production service. Remote GitHub delivery and Git
  identity/import adapters remain design-only.
- The prebuilt artifact is Linux x86_64 GNU only. No crates.io, GHCR, Windows,
  macOS, or Linux ARM64 package is published.

Stage 0 APIs and formats do not yet carry a stable compatibility promise.
Export important repositories with the old binary before updating so that a
known-good recovery copy remains available.
