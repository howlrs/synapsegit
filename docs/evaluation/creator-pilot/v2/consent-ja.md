# 参加の説明と同意書（Creator pilot v2）

この説明を読んでから、参加するかどうかと、記録してよい範囲を選んでください。
参加は任意です。途中でやめても、理由を説明する必要はありません。

## 何のための評価か

SynapseGitは、AIの提案と人の判断を、自分のコンピューターの中に記録するツールです。
この評価では、v1.0の正式公開前の版（release candidate）を使ってもらい、使いにくい点や
誤解しやすい言葉、記録が失われるような重大な問題がないかを確かめます。
あなたの能力を測るテストではありません。

## すること

1. あなたのAIエージェントに頼んで、練習用のプロジェクトを作り、候補（3つの画像）を置いてもらいます。
2. ブラウザの画面で候補を確認し、採用・不採用・保留のいずれかを自分で選んで記録します。
3. 記録を読み返し、backupを作ります。
4. いくつかの質問に、自分の言葉で答えます。

予定時間は60〜90分です（目安であり、早く終えることは求めません）。

## 使う素材

- 標準では、SynapseGitに付属する練習用の画像（壁画の合成画像）を使います。
- 自分の作品を使うかどうかは、あなたが選べます。使う場合、作品はあなたのコンピューターの中だけに
  保存されます。進行役は作品のファイルを受け取らず、コピーしません。
- **AIエージェントについて:** あなたが使うAIエージェントは、頼んだ内容やファイルの内容を、
  そのサービスの提供元へ送ることがあります。これはSynapseGitではなく、エージェントの提供元の
  規約によります。自分の作品や非公開の情報を使う場合は、この点を確認してから決めてください。
  迷う場合は練習用の画像を使ってください。

## 記録すること・しないこと

進行役が記録するのは、次の観察だけです。

- どの課題を終えたか、どこで手助けが必要だったか、誤解した言葉、負担に感じた操作
- 課題ごとのおおよその時間（目標値ではなく、観察として）
- 質問への回答の要点
- 見つかった問題（不具合、分かりにくい表示など）

次は記録しません。

- あなたの氏名、連絡先、所属
- あなたの作品の画像やタイトル
- あなたが書いた判断の理由や、AIへの指示（プロンプト）の原文

## 公開について

結果は、個人を特定できない形に要約して、SynapseGitのrepository（文書やIssue）に記録します。
あなたは参加者ID（例: `P1`）としてだけ表されます。

## やめたいとき

いつでも中止できます。公開前の記録は、申し出があれば削除します。公開した要約は、
個人を特定できる情報を含まない形で残ります。
