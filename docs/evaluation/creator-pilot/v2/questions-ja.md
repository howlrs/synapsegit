# 質問（Creator pilot v2）

自分の言葉で答えてください。画面や文書を見返しながら答えて構いません。正解を当てるテストではありません。
分からない場合は「分からない」と書いてください。それも大切な記録です。

## 記録の意味について

1. 3枚目の画像（AI output）は、どこから来たものですか。SynapseGitはその画像に対して何をしましたか。
2. レビュー画面の「ファイル内容の一致確認」は、何を教えてくれますか。また、何を教えてくれませんか。
3. 記録した判断を、後から変えたくなったとします。どうなりますか。どうすればよいですか。
4. 今日の作業のうち、AIエージェントが行ったことと、あなたが行ったことを分けて説明してください。
5. 課題6で作ったbackupは、どこにありますか。何が入っていると思いますか。

## 振り返り

6. いちばん分かりにくかった言葉や画面はどれですか。どう読み違えそうになりましたか。
7. 記録のために手間がかかると感じた操作はどれですか。記録の負担を1（軽い）〜5（重い）で表すと、
   いくつですか。その理由も教えてください。
8. 記録を読み返したとき、自分が何を判断し、なぜそう判断したかを説明できましたか。
   説明に役立った表示や記録はどれですか。
9. AIエージェントへの頼み方で困ったことや、エージェントの説明で分かりにくかったことはありますか。
10. 自分の制作で使うとしたら、どんな場面ですか。使わないとしたら、その理由は何ですか。
11. その他、気づいたことがあれば自由に書いてください。
